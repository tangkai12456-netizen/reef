วิธีการทำงานของระบบ (Methodology)

เอกสารนี้อธิบายว่า ReefAlert ดึงข้อมูลจากไหน ตรวจสอบความถูกต้องยังไง โมเดล Machine Learning ที่ใช้พยากรณ์ DHW ทำงานอย่างไร และข้อจำกัดของระบบ — ตัวเลขทั้งหมดในหน้านี้ (คะแนนโมเดล, feature importance) ดึงมาจากไฟล์ผลการเทรนจริง (dhw_model_meta.json) ไม่ได้พิมพ์ตายตัวไว้ในหน้าเว็บ

1แหล่งข้อมูล (Data Sources)
ข้อมูลแหล่งที่มาความละเอียดข้อจำกัด
DHW (Degree Heating Weeks) NOAA Coral Reef Watch ผ่าน PacIOOS ERDDAP mirror ~5 กม./pixel เป็นค่าปัจจุบัน/ย้อนหลังจากดาวเทียม ไม่ใช่พยากรณ์ (ต้องใช้โมเดล ML ของเราเองพยากรณ์ล่วงหน้า)
SST (อุณหภูมิผิวน้ำ) Open-Meteo Marine API รายชั่วโมง พยากรณ์ล่วงหน้าได้จริงแค่ ~10 วัน (ขอ 14 วันแต่ 4 วันสุดท้ายไม่มีข้อมูล)
UV Index Open-Meteo Forecast API รายชั่วโมง —

NOAA Coral Reef Watch เป็นหน่วยงานที่เผยแพร่มาตรฐาน Bleaching Alert Level ที่ใช้กันทั่วโลก เราเลือกดึงผ่าน PacIOOS ERDDAP mirror แทนการยิงตรงไปที่ endpoint ของ NOAA เอง เพราะ endpoint ของ NOAA โดยตรงมีปัญหา CORS/ไม่ตอบสนองจากฝั่ง browser

2การตรวจสอบความถูกต้องของข้อมูล (Data Validation)

✅ ยืนยันพิกัดทั้ง 8 จุดตกในทะเล ไม่ใช่บนแผ่นดิน

ตรวจสอบทีละจุดโดยดึงข้อมูลกริด NOAA รอบพิกัดจริง (±0.25°) แล้วเทียบว่า "จุดกริดที่ใกล้พิกัดที่ตั้งไว้ที่สุด" กับ "จุดกริดที่ใกล้สุดที่มีข้อมูลจริง (ไม่ใช่ null)" เป็นจุดเดียวกันหรือไม่ — ผลคือ ตรงกันทั้ง 8 จุด (ห่างจากพิกัดที่ตั้งไว้เพียง 0.7–3.7 กม.) ยืนยันว่าไม่มีจุดไหนตกบน cell ที่เป็นแผ่นดิน/ไม่มีข้อมูล

✅ ตรวจสอบว่าค่า 0 เป็นข้อมูลจริง ไม่ใช่ null ที่ถูกแปลง

โค้ดฝั่งแอปกรอง null/NaN ออกก่อนเลือก pixel ที่ใกล้ที่สุดเสมอ (ไม่มีการแปลง null → 0 ที่ไหนเลย) ตรวจสอบเพิ่มด้วยการ print raw JSON response ตรงจาก NOAA — กรณีเกาะสมุยที่ค่า DHW ปัจจุบันเป็น 0 นั้น ยืนยันจาก raw response แล้วว่าเป็นเลข 0 จริง ไม่ใช่ null

✅ ทดสอบขยาย search radius เพื่อยืนยันว่าเลือก pixel ใกล้ที่สุดจริง

ขยายรัศมีค้นหาจาก ±0.25° เป็น ±0.5° แล้วเทียบผล — ได้ค่า DHW และระยะห่างจาก pixel เดิมทุกจุดเหมือนกัน 100% ยืนยันว่ารัศมีที่ใช้งานจริง (±0.25°) เพียงพอ และไม่มี pixel ที่ใกล้กว่านี้ถูกมองข้ามไป

4เกณฑ์การประเมินความเสี่ยง (ตามมาตรฐาน NOAA)
DHW (°C·weeks)ระดับความหมาย
< 1🟢 ปกติNo Stress — ไม่มีความเครียดจากความร้อนสะสม
1 – 3.9🟡 เฝ้าระวังBleaching Watch — เริ่มสะสมความร้อน ควรติดตามใกล้ชิด
4 – 7.9🟠 สูงAlert Level 1 — เสี่ยงฟอกขาวสูง
≥ 8🔴 วิกฤตAlert Level 2 — ปะการังฟอกขาว/ตายเป็นวงกว้าง

เกณฑ์นี้คือ Bleaching Alert Level ของ NOAA Coral Reef Watch ที่ใช้กันเป็นมาตรฐานสากล ระบบใช้ DHW เป็นเกณฑ์หลักเสมอเมื่อมีข้อมูล ถ้ายังไม่มี DHW จะ fallback ไปประมาณจาก SST ชั่วคราวแทน

5ข้อจำกัดของระบบ (Limitations)
⚠️
พึ่งพา server ภายนอก (PacIOOS) — ข้อมูล DHW ทั้งหมดดึงจาก PacIOOS ERDDAP mirror ซึ่งเป็นบริการฟรีที่พบว่าบางครั้งไม่เสถียร/ตอบสนองช้าหรือ timeout ไม่มีการควบคุมความเสถียรของ server นี้ได้เลย
⚠️
โมเดลพยากรณ์มีความคลาดเคลื่อนจริง — MAE เฉลี่ยประมาณ ~1.0 °C·weeks และยิ่งพยากรณ์ไกลออกไปยิ่งคลาดเคลื่อนมากขึ้น (ดูตาราง MAE ตาม horizon ด้านบน) ไม่ควรใช้เป็นตัวเลขที่แม่นยำ 100% ควรใช้ประกอบการตัดสินใจร่วมกับข้อมูลอื่นเสมอ
⚠️
ครอบคลุมเฉพาะ 8 จุดในน่านน้ำไทย — ไม่ใช่ระบบเฝ้าระวังปะการังทั่วโลก และโมเดล ML ถูกเทรนจากข้อมูลของ 8 จุดนี้เท่านั้น การใช้กับพื้นที่อื่นอาจไม่แม่นยำเท่า
⚠️
SST พยากรณ์ล่วงหน้าได้จริงแค่ ~10 วัน — จากทั้งหมด 14 วันที่แอปแสดง (ข้อจำกัดของ Open-Meteo API ฟรี)
